# KS 全局工作台 UI 改版

## 目标

将相似专题原型中更干净、低噪音、单任务聚焦的视觉语言提升为全局 KS 工作台设计系统，使 Learn、Topic Learn、Practice 与 Similarity 在字体、密度、表面、指导栏和动作区上使用同一套基础规则。

Similarity 不再拥有一套孤立的页面皮肤；它只保留学习图谱拓扑、节点连线、lane 和 challenge 形状等领域专属表现。

## 核心原则

1. 题目、主对象、当前指导和当前动作在桌面端同屏呈现。
2. 正常桌面视口不产生页面级纵向滚动。
3. 一次只强调一个主动作，减少重复标题、嵌套卡片、阴影和装饰。
4. 全局视觉规则以语义令牌和通用工作台构型提供，不以 `similarity-*` 页面选择器复用。
5. 数学图谱拓扑、题图命中区域和具体输入器仍由各自领域样式负责。
6. 窄屏允许自然滚动，不以裁切内容换取形式上的“无滚动”。

## 范围

- 全局设计令牌与字体层级
- 通用焦点工作台构型
- Topic Learn 迁移
- 普通 Learn 迁移
- Practice 页面外壳迁移
- Similarity 页面样式回收
- 桌面固定视口与局部溢出策略
- 响应式、键盘操作和视觉回归

## 非目标

- 重做学习图谱的数据与进度算法
- 改变 Learn / Practice / Review 的领域职责
- 重写数学题图渲染器
- 强制所有内容型页面禁止滚动
- 原样恢复旧版重卡片时间线
