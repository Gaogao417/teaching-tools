# PRD-01：相似专题学习图谱

## 文档状态

- 状态：Draft
- 优先级：P0
- 依赖：PRD-02 能力进度与解锁规则
- 后续依赖方：PRD-04 综合挑战关、PRD-05 补强回路

## 1. 背景与问题

当前 `SidebarNav` 将五个专题作为同一章节下的五个文本按钮平铺展示。存在以下问题：

- “相似、对应边求长”等词语重复，五个入口的差异难以扫描。
- 入口没有表达 `平行线比例 → 比例辅助线` 等真实前置关系。
- 学生不知道自己停在哪里、下一步为什么是这个专题。
- 锁定、可学习、正在学习和已掌握没有统一状态。
- 返回学习时必须重新打开抽屉、展开年级与章节、扫描列表。

## 2. 产品目标

- 用一张有向图表达五专题的学习路径和挑战分支。
- 首屏优先回答“我现在在哪里”和“下一步做什么”。
- 学生可以理解任一锁定节点的原因，并一键回到缺失前置。
- 保留 Learn / Practice / Review 的路由边界，不把地图变成第四种学习模式。

## 3. 非目标

- 不在前端计算掌握度或解锁状态。
- 不允许在地图上直接作答。
- 不在首版提供自由拖拽、缩放或编辑图谱。
- 不替换其他年级和章节的现有任务树。

## 4. 信息架构

五个学习节点组织为三层：

```text
01 比例原型
└── 平行线比例

02 组合建模
└── 比例辅助线

03 构型迁移
├── 反 A 形
├── 子母型
└── 蝶形
```

首版推荐依赖图：

```text
平行线比例 ──▶ 比例辅助线
      │
      └──────▶ 反 A 形 ──▶ 子母型
                         └▶ 蝶形
```

最终边关系必须来自后端图谱定义，前端只负责渲染。

## 5. 核心页面

### 5.1 图谱入口

入口替代相似章节当前的五项平铺列表，其他章节保持原样。

页面必须包含：

- 学生当前位置或最近学习节点。
- 五个专题节点及有向连接线。
- 与节点状态一致的视觉编码。
- 可见的下一推荐节点。
- 综合挑战节点的独立形状；挑战节点由 PRD-04 提供数据。

禁止：

- 每个专题使用一套装饰性色彩。
- 在节点上展示长摘要、题干或完整步骤。
- 默认展示所有依赖说明和所有历史数据。

### 5.2 节点详情面板

学生点击节点后，在同页打开轻量详情面板，不立即跳转。

详情内容：

- 专题名。
- 本专题唯一新增的能力。
- 已具备的前置能力摘要。
- 当前进度或锁定原因。
- 一个主操作和至多一个次操作。

按钮规则：

| 节点状态 | 主操作 | 次操作 |
| --- | --- | --- |
| 可学习 | 开始学习 | 直接训练 |
| 进行中 | 继续学习 | 继续训练 |
| 已掌握 | 再练一组 | 查看复盘 |
| 锁定 | 回到缺失前置 | 无 |
| 挑战 | 直接挑战 | 先补前置 |

## 6. 节点状态

地图消费 PRD-02 提供的状态：

- `locked`：尚未满足硬前置。
- `available`：可开始。
- `in_progress`：已有学习或训练记录，但尚未掌握。
- `mastered`：已达到掌握标准。
- `recommended`：在当前状态下最推荐的下一节点；它是叠加状态，不替代以上状态。

交互规则：

- 锁定节点仍可点击查看原因。
- 当前节点和推荐节点可以同时存在，但最多各一个。
- 首次打开时自动聚焦最近节点，不自动打开详情面板。
- 从补强回路返回时，聚焦原挑战节点而非最近学习节点。

## 7. 路由与导航

- 进入节点学习：`/learn/:taskId`
- 进入节点训练：`/practice/:taskId`
- 进入复盘：`/review/:taskId`
- 地图作为相似章节入口，不改变上述模式语义。
- 从 active Practice 返回地图前，继续使用现有未提交草稿导航保护。

建议新增稳定路由：

```text
/map/similarity
```

移动端从顶部菜单进入地图；桌面端可由任务抽屉中的“相似与比例”章节进入。

## 8. 数据需求

建议新增只读响应：

```ts
type LearningMapResponse = {
  mapId: "similarity-v1";
  nodes: Array<{
    id: string;
    kind: "topic" | "challenge";
    taskId?: TaskId;
    title: string;
    actionLabel: string;
    state: "locked" | "available" | "in_progress" | "mastered";
    recommended: boolean;
    progress?: { completed: number; total: number };
    missingPrerequisiteIds: string[];
  }>;
  edges: Array<{
    from: string;
    to: string;
    kind: "required" | "challenge-requires";
  }>;
  focusedNodeId?: string;
};
```

前端不得通过 `TaskHistoryItem` 自行推导节点状态。

## 9. 验收标准

1. 五个专题能在一屏内看见，320px 宽度下允许纵向重排但不横向滚动。
2. 学生能在不进入节点的情况下识别当前位置、下一节点和锁定原因。
3. 点击锁定节点后，主操作能跳转到具体缺失前置节点。
4. 点击可学习节点不会立即跳转，必须先显示节点详情。
5. Learn / Practice / Review 切换不改变当前 `taskId`。
6. 图谱不可因没有训练历史而显示空白或无法开始。

## 10. 埋点

- `learning_map_opened`
- `learning_map_node_selected`
- `learning_map_locked_node_inspected`
- `learning_map_prerequisite_clicked`
- `learning_map_primary_action_clicked`

核心指标：从打开地图到进入有效学习/训练的中位操作次数不超过 2 次点击。
