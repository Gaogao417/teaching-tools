# PRD-01：相似专题学习图谱

## 文档状态

- 状态：Implemented
- 优先级：P0
- 依赖：PRD-02 能力进度与开启规则
- 后续依赖方：PRD-04 综合挑战关、PRD-05 补强回路

## 1. 背景与问题

当前 `SidebarNav` 将五个专题作为同一章节下的五个文本按钮平铺展示。存在以下问题：

- “相似、对应边求长”等词语重复，五个入口的差异难以扫描。
- 入口没有表达 `平行线比例 → 比例辅助线` 等真实前置关系。
- 学生不知道自己停在哪里、下一步为什么是这个专题。
- 节点混用锁定、可学习、正在学习和已掌握等状态，学生容易把学习顺序误解为访问权限。
- 返回学习时必须重新打开抽屉、展开年级与章节、扫描列表。

## 2. 产品目标

- 用一张有向图表达五专题的学习路径和挑战分支。
- 首屏优先回答“我现在在哪里”和“下一步做什么”。
- 所有知识点统一显示“未开启 / 开启 / 通关”；前置关系决定专题何时开启，但界面不再使用锁图标或“锁定 / 解锁”语言。
- 学生可以在图谱上快速预览每个知识点的代表题，再决定进入哪个专题。
- 保留 Learn / Practice / Review 的路由边界，不把地图变成第四种学习模式。

## 3. 非目标

- 不在前端计算掌握度、节点进度或推荐顺序。
- 不允许在地图上直接作答。
- 不在首版提供自由拖拽、缩放或编辑图谱。
- 不替换其他年级和章节的现有任务树。

## 4. 信息架构

五个学习节点组织为三层：

```text
01 比例原型
└── 平行线比例

02 组合建模
└── 比例辅助线

03 构型迁移
├── 反 A 形
├── 子母型
└── 蝶形
```

首版推荐依赖图：

```text
平行线比例 ──▶ 比例辅助线
      │
      └──────▶ 反 A 形 ──▶ 子母型
                         └▶ 蝶形
```

最终边关系必须来自后端图谱定义，前端只负责渲染。

## 5. 核心页面

### 5.1 图谱入口

入口替代相似章节当前的五项平铺列表，其他章节保持原样。

页面必须包含：

- 学生当前位置或最近学习节点。
- 五个专题节点及有向连接线。
- 与节点状态一致的视觉编码。
- 可见的下一推荐节点。
- 每个节点左侧的状态图标同时是独立的题目预览触发器；鼠标悬浮或键盘聚焦图标时可查看代表题。
- 综合挑战节点的独立形状；挑战节点由 PRD-04 提供数据。

节点卡片固定只显示三类信息：左侧状态图标、知识点名称、三态文案。三态文案只能是“未开启”“开启”“通关”，不得被“建议下一步”“可以开始”“正在进行”“已经掌握”或挑战类型替代。`recommended` 使用卡片外描边、连接线强调或页头“下一步”提示表达，不新增第四种状态标签；`actionLabel` 放在详情面板，不占用节点状态行。

禁止：

- 每个专题使用一套装饰性色彩。
- 直接在节点卡片上常驻展示长摘要、题干或完整步骤。
- 默认展示所有依赖说明和所有历史数据。
- 使用锁图标、禁用态、不可点击态或“尚未解锁”等文案表达节点状态。

### 5.2 节点详情面板

学生点击节点后，在同页打开轻量详情面板，不立即跳转。

详情内容：

- 专题名。
- 本专题唯一新增的能力。
- 已具备的前置能力摘要。
- 当前进度或尚未满足的开启条件。
- 一个主操作和至多一个次操作。

按钮规则：

| 节点状态 | 主操作 | 次操作 |
| --- | --- | --- |
| 未开启 | 学习缺失前置 | 无 |
| 开启 | 开始 / 继续学习 | 直接 / 继续训练 |
| 通关 | 再练一组 | 查看复盘 |

挑战节点也只使用这三种状态：未开启时“直接挑战”，开启时“继续挑战”，通关后“再次挑战 / 查看复盘”。建议前置可在详情中查看，但不替代主操作，也不阻止进入挑战。

## 6. 节点状态

地图消费 PRD-02 提供的三种节点状态，学生可见文案不得出现其他状态名：

- `unopened` / 未开启：普通专题尚未满足开启条件；挑战节点尚未被主动开启。
- `open` / 开启：普通专题已满足开启条件，或挑战节点已被主动开启，但尚未达到通关条件；是否已有学习记录不改变这个状态名。
- `passed` / 通关：已经达到该节点的通关条件。
- `recommended`：在当前状态下最推荐的下一节点；它是叠加状态，不替代以上状态。

交互规则：

- 未开启节点仍可点击查看详情和预览题目。普通专题的主操作跳到具体缺失前置；挑战节点遵循软门槛，仍可“直接挑战”，首次进入后变为开启。
- 未开启节点不得使用锁图标；建议使用空心圆，开启使用播放/进度图标，通关使用完成图标。挑战节点可保留独立外形，但状态图标仍遵循三态。
- 当前节点和推荐节点可以同时存在，但最多各一个。
- 首次打开时自动聚焦最近节点，不自动打开详情面板。
- 从补强回路返回时，聚焦原挑战节点而非最近学习节点。

### 6.1 图标题目预览

- 预览触发区是节点左侧的状态图标；该图标作为独立控件，不把整个节点卡片变成 hover 触发区。
- 鼠标悬浮或键盘聚焦图标时，在图标旁打开轻量预览层；指针移入预览层时保持打开，移出图标和预览层、失焦或按 `Escape` 后关闭。
- 预览展示一题来自该节点已批准题库的稳定代表题，包含题干和必要题图，不展示答案、解析、作答控件或学习步骤。
- 题干中的数学公式必须正常排版，不显示原始 LaTeX；题图按原始宽高比缩放并提供替代文本。
- 预览只用于浏览，不创建 session、不改变节点状态、不计入学习历史。
- 状态图标与节点主按钮必须是两个独立交互元素，避免点击图标预览时同时选中或进入节点。
- 触摸设备没有 hover：点击预览图标打开，再次点击、点击外部或按返回关闭；窄屏时预览改为底部浮层，不造成横向滚动。
- 预览题缺失或资源失效时显示“题目预览暂不可用”，节点本身仍可正常打开。

## 7. 路由与导航

- 进入节点学习：`/learn/:taskId`
- 进入节点训练：`/practice/:taskId`
- 进入复盘：`/review/:taskId`
- 地图作为相似章节入口，不改变上述模式语义。
- 从 active Practice 返回地图前，继续使用现有未提交草稿导航保护。

建议新增稳定路由：

```text
/map/similarity
```

移动端从顶部菜单进入地图；桌面端可由任务抽屉中的“相似与比例”章节进入。

## 8. 数据需求

建议新增只读响应：

```ts
type LearningMapResponse = {
  mapId: "similarity-v1";
  nodes: Array<{
    id: string;
    kind: "topic" | "challenge";
    taskId?: TaskId;
    title: string;
    actionLabel: string;
    state: "unopened" | "open" | "passed";
    recommended: boolean;
    progress?: { completed: number; total: number };
    missingPrerequisiteIds: string[];
    previewQuestion?: {
      questionId: string;
      stemLatex: string;
      diagramAssetUrl?: string;
      diagramAlt?: string;
    };
  }>;
  edges: Array<{
    from: string;
    to: string;
    kind: "required" | "challenge-requires";
  }>;
  focusedNodeId?: string;
};
```

前端不得通过 `TaskHistoryItem` 自行推导节点状态。`previewQuestion` 必须来自已批准题库的服务端投影，在线运行时不生成新题。

## 9. 验收标准

1. 五个专题能在一屏内看见，320px 宽度下允许纵向重排但不横向滚动。
2. 所有专题与挑战节点的状态行只显示未开启、开启、通关；“建议下一步”等推荐信息不占用状态行，页面中没有锁图标或“锁定 / 解锁”文案。
3. 未开启节点可以打开详情和题目预览；普通专题的主操作能跳到具体缺失前置，挑战节点仍保留“直接挑战”。
4. 悬浮或键盘聚焦任一节点的预览图标时能看到对应代表题；关闭预览后焦点返回触发图标，且预览不会改变进度。
5. 点击节点不会立即跳转，必须先显示节点详情；点击预览图标不得同时选中节点。
6. Learn / Practice / Review 切换不改变当前 `taskId`。
7. 图谱不可因没有训练历史或预览题缺失而显示空白或无法开始。

## 10. 埋点

- `learning_map_opened`
- `learning_map_node_selected`
- `learning_map_question_preview_opened`
- `learning_map_suggested_prerequisite_clicked`
- `learning_map_primary_action_clicked`

核心指标：从打开地图到进入有效学习/训练的中位操作次数不超过 2 次点击。
