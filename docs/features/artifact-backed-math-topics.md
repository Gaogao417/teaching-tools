# 题库产物驱动的数学专题学习与训练

## 目标

四个专题不再共用“读摘要—选标签—填最终答案”的壳。`teaching_skills` 中最终生成并经人工修改的 explanation TeX 是学习内容与图文编排的事实源；题库 YAML 只负责题号、答案、教学诊断和图资源索引。本仓库通过离线导入，把两者编译成版本化场景包。在线运行时只读取场景包，不跨仓库读 TeX 或 YAML。

## 用户故事

### 二次函数配方

学生面对同一个一般式，依次完成“提取二次项系数—按 `x²+2mx` 找到 `m`—补成完全平方—拆括号并合并常数”。每次只改变算式的一个状态；已完成的等式链一直保留。系统判断的是本步得到的数学表达式，不是“我现在在配方”这一类方法标签。

### 三角形一边平行线

学生先从真实题图和题干读点序，判断已知的是分段还是相似三角形的整段；再写相似三角形与顶点对应；最后把同方向对应边比例转移到所求。A 字与 8 字使用各自 explanation 中的真实图，不由前端猜构型。

### 比例辅助线两组整数比

学生在原题图上选择正确的平行辅助线，随后观察题库给出的逐步图：第一组相似标出的份数不能在第二组中消失；第二组只补共同边连接出的新份数；最后比较目标边。页面必须保存同一个图形对象的逐步状态，不能每一步重画一张无关示意图。

### 各种相似

学生按反 A、子母、蝶形分别训练。先找到构型自带的第二组等角，再按角的顶点顺序建立三角形对应，随后列同方向比例。子母型在列比例前显式完成共线边互化；页面不把三种构型压成一个“识别模型”的泛化动作。

## 界面结构

学习页与训练页必须复用同一个可操作数学对象、同一个动作工作台、同一个提交按钮和同一套判定逻辑。二者唯一的教学差异是：学习页在右侧持续展示完整流程、当前提示和易错提醒；训练页不展示这条全流程侧栏。

顶部完整呈现题干；中央显示题库的 prompt SVG 与由 `tikz_spec.json` 编译出的可点击点线层；下方是当前动作工作台。学生完成动作后，同一位置切换为该题对应的下一阶段 SVG，并保留已经标出的边长或份数。训练题的题干、图、答案和动作步骤必须具有同一个题目 ID 与来源路径。

### 平行线比例与相似求边的共同动作

1. 在题图上点击题干给出的线段，逐段标出边长或份数。
2. 点击对应线段，把同一组比例标到图上。
3. 列出 `未知 = 已知 × 未知份数 / 已知份数`，再计算结果。

反 A、子母、蝶形是三个独立专题、三个入口和三套场景库，不使用“各种相似”总入口。子母型的共线边换算属于第一步标边长的一部分。

### 比例辅助线动作

1. 先点击过线点，再点击作为方向参照的线段；随后点击平行线外的两个点，连接两点并与新平行线相交，生成辅助点。
2. 在 helper 图上点击第一组模型要求的线段，输入份数；成功后切换到 model1 图。
3. 在保留已有份数的 model1 图上点击第二组模型新增的线段，输入份数；成功后切换到 model2 图。
4. 根据图上目标边份数列式并写出最终比。

## 用户动作契约

每一步都编译为以下契约，运行时不得根据页面文案临时推断：

| 字段 | 含义 |
| --- | --- |
| `primitive` | `select`、`input` 或 `compose` |
| `target` | 本步唯一可操作的工作台目标 |
| `promptLatex` | 学生此刻要完成的具体数学动作 |
| `options` / `acceptedAnswers` | 允许提交的结构化选择或规范答案 |
| `expectedLatex` | 教师版该步的数学结果 |
| `successCondition` | 进入下一状态所需满足的条件 |
| `errorDiagnosis` | 本步错误对应的诊断，不清空之前的正确状态 |
| `feedbackLatex` | 正确后写回数学对象的内容 |
| `diagramAsset` | 本步完成后应显示的真实题库图 |
| `nextStepId` | 成功后的唯一下一状态 |

在线交互遵守“一次一个主动作”：`select/input -> submit -> feedback -> next`。错误只修正当前动作；已完成的表达式、对应关系或图上份数继续保留。

## 内容边界

离线导入器验证：学习内容来自最终 explanation TeX；题库状态为 `ready`；manifest 中启用题目的 teacher assignment 存在；题目块包含题干和答案；diagram job 能解析到浏览器可显示的 SVG。导入结果记录源 TeX、源 YAML、题目 ID、题库 ID 和 bundle 版本，供界面展示与测试追踪。
