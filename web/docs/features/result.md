# Result Feature Spec

## 摘要

结果页现在是 `WorkspaceShell` 内部的结果子路由，而不是独立脱离 workspace 的页面。

它负责展示一次训练完成后的结果快照，并让学生在同一工作区内继续训练或回到任务概览。

## 当前结构

```text
WorkspaceShell
  -> ResultPage
```

## 页面职责

`ResultPage` 负责：

- 从后端读取持久化的 `ResultSnapshot`
- 展示本次成绩与历史趋势
- 在进入结果页时回写 shell 的 focused task，保持导航状态一致
- 提供“再练一组”和“回到概览”入口

结果页不负责：

- 重新判题
- 保存草稿
- 依赖上一页内存继续工作

## 数据来源

结果页数据必须来自后端持久化结果。

这意味着：

- 刷新结果页后仍然可恢复
- 结果页不依赖前一页把完整对象塞进路由状态

## 与壳层的关系

结果页与练习页、概览页共享同一个 `WorkspaceShell`。

因此：

- 结果页外围导航与身份上下文由 shell 提供
- 结果页进入时需要同步 focused task，保证侧边导航和后续返回动作一致
- 返回概览不再表示离开产品壳层，只是回到 shell 的 index panel

## 关键交互

- 从练习完成弹层进入结果页
- 在结果页点击“再练一组”后跳回 `/practice/:taskId`
- 在结果页点击“回到概览”后跳回 `/`

## 验收条件

- 学生一进结果页就能看懂本次成绩
- 页面刷新后结果不丢
- 结果页与 workspace 壳层保持统一导航和视觉上下文
- 从结果页可以无歧义地继续同任务训练或返回任务概览
