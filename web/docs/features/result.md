# Result Feature Spec

## 摘要

结果页是练习闭环的终点页面。

它负责展示本次训练结果与历史趋势，但不承担练习流程本身。

## 页面职责

- 展示本次成绩
- 展示当前任务维度的历史趋势
- 提供返回任务首页和继续练习入口

结果页不负责：

- 重新判题
- 保存草稿态
- 依赖前一页内存继续工作

## 数据来源

结果页的数据必须来自后端持久化结果。

这意味着：

- 刷新结果页仍然可恢复
- 结果页不依赖前一页把完整对象塞进路由状态

## 页面结构

- 标题区
- 指标卡区
- 趋势图区
- 操作区

## 关键交互

- 从练习完成层进入结果页
- 在结果页继续发起新一组练习
- 返回首页重新选择任务

## 验收条件

- 学生一进结果页就能看懂本次成绩
- 页面刷新后结果不丢
- 与练习页在视觉语言上连续
