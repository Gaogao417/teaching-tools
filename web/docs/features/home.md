# Home Feature Spec

## 摘要

首页是任务门户，不是练习主战场。

它负责把学生带到正确任务，并让学生在开始前获得足够但不过量的信息。

## 页面职责

- 输入和修改学生姓名
- 浏览任务树
- 查看任务摘要、样题和步骤说明
- 查看当前学生的最近历史记录
- 进入练习页

首页不负责：

- 判题
- 练习交互
- 结果总结

## 信息架构

首页应包含：

- 顶部学生信息区
- 课程树或任务导航区
- 当前任务详情区
- 开始练习 CTA

桌面端默认双栏，移动端优先任务详情区。

## 状态来源

首页依赖：

- `task tree`
- `task history`
- 本地保存的 `studentName`

首页本地状态只应包括：

- 当前展开的课程树节点
- 当前选中的任务
- 当前学生姓名输入态

## 关键交互

### 学生姓名

- 未填写姓名时，开始练习不可用
- 填写后写入本地缓存
- 修改姓名后应刷新历史数据

### 任务浏览

- 点击任务后刷新详情区
- 首次进入应有默认选中任务
- 不应要求学生先读完整长文再开始

### 开始练习

- 点击后进入 `/practice/:taskId`
- 练习 session 由练习页负责创建
- 首页只负责导航，不负责偷跑练习态

## 验收条件

- 学生能在首页 10 秒内找到可开始的任务
- 未填写姓名时不会误入练习页
- 任务详情足以让学生知道“这是练什么”
- 历史记录按当前学生显示，不串人
