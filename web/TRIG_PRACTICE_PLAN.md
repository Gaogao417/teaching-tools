# 三角比速度训练 - 重构 Plan

## 1. 重构目标

把当前页面改造成“强引导型教学界面”，不是普通练习页。

目标节奏统一为：

`看题 -> 操作 -> 立即反馈 -> 自动下一题 -> 自动成绩弹层`

核心要求：

- 学生始终只关注一个当前任务
- 练习页成为主战场，首页只做入口
- 三边角色建立稳定颜色认知
- 三组题共用统一的自动流转逻辑
- 成绩先弹 modal，再允许进入详细结果页

---

## 2. 视觉方向

### 2.1 视觉关键词

- 课堂教具板
- 温暖纸面
- 深墨色正文
- 强步骤引导
- 稳定、短促、不花哨的动画

### 2.2 固定角色配色

全站统一，不随 group 变化：

- 对边：橙红
- 邻边：青绿
- 斜边：蓝灰

### 2.3 页面层级

练习页固定分成 3 区：

- 顶部：当前组标题、题号、进度条、计时、返回/重开
- 中央：大三角形 + 当前操作区
- 底部：反馈、规则提示、DeepSeek 提示入口

### 2.4 首页定位

首页只承担入口作用：

- 标题
- 3 个训练组入口
- 每组轻量统计或趋势图
- 设置入口

不再把大量说明文字和练习流程堆在首页。

## 4. 三组交互目标

### 4.1 Group 1：认清定义

目标：建立“一个三角比 = 两种边角色的有序比”的反射。

界面要求：

- 公式卡居中放大，例如 `sin A`
- 下方两个槽位：`分子边`、`分母边`
- 三条边是大点击热区
- 点击第一下后，界面立即提示“再点分母边”

### 4.2 Group 2：由比找边

目标：让学生把比值真正落到边上。

界面要求：

- 公式卡居中显示，例如 `sin A = 1/2`
- `1`、`2` 使用大号数字卡片
- 三角形边上直接显示投放框
- 选中数字后，只高亮可放目标区

### 4.3 Group 3：分步求值

目标：形成稳定的解题动作链。

界面要求：

- 改为 stepper / wizard
- 一次只展开当前一步
- 后续步骤折叠或锁定
- 每步顶部有一句极短教师口令：
  - 先把已知长度标到边上
  - 再化成最简 z 比
  - 再补第三边
  - 最后代回目标三角比
- 当前步正确后自动展开下一步

## 5. 自动流转逻辑

### 5.1 每题答对

- 立即显示绿色“答对了”
- 锁定当前操作
- `700ms` 后自动进入下一题
- 支持 `Enter` 立即跳过等待

### 5.2 每题答错

- 不自动跳题
- 保留当前题
- 给出“下一步该看什么”的提示，而不是只有报错

### 5.3 一组做完

- 最后一题答对后 `900ms`
- 自动弹出成绩 modal

modal 内容：

- 本次耗时
- 最佳耗时
- 最近平均
- 小折线图
- 再来一组
- 查看详细结果
- 返回首页

### 5.4 详细结果页

- 结果页保留
- 但不再作为第一落点
- 流程为：`做完 -> modal -> 详细结果页（可选）`

---

## 6. 状态设计

增加统一 phase：

- `answering`
- `correct_pause`
- `wrong_feedback`
- `group_finished`
- `result_page`

增加统一计时器：

- `pendingAdvanceTimer`
- `pendingResultModalTimer`

原则：

- 三组共用一套自动流转逻辑
- 首页、modal、结果页读取同一份历史统计数据

---

## 7. 实施顺序

- `P1` 重画练习页骨架
- `P2` 统一视觉系统：色板、边角色颜色、公式卡、动作提示条
- `P3` 重写 3 个 group 的交互组件
- `P4` 接入统一自动下一题和成绩 modal
- `P5` 微调动画、移动端点击区、提示文案

| 视觉方向 | 课堂教具板 |
| 自动下一题延迟 | 700ms |
| 自动成绩弹层延迟 | 900ms |
| Group 3 展示方式 | 一次只显示当前步骤 |

---

## 9. 验收标准

- 做对后无需手动点“下一题”
- 一组做完无需手动点“查看成绩”
- 学生始终知道“现在该做哪一步”
- 对边 / 邻边 / 斜边能一眼区分
- Group 3 体现明确步骤推进
- modal -> 详细结果页流转顺畅
- 历史数据不丢失、不重复、不冲突
